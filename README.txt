CARA UPLOAD KE GITHUB PAGES
1. Ekstrak ZIP ini.
2. Buka repository GitHub website BeeAyu.
3. Upload isi folder BeeAyu_Premium ke root repository, bukan file ZIP-nya.
4. Pastikan index.html, style.css, script.js berada di root. Folder assets berisi logo.png dan banner.png.
5. Buka Settings > Pages, pilih Deploy from a branch, branch main, folder /(root), lalu Save.
